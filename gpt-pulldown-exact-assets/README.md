# GPT Pull-down Exact Web Assets

These assets are generated directly from the uploaded GPT Pull-down logo image, without redrawing or reinterpreting the logo.

## Recommended use

| File | Use |
| --- | --- |
| `logo-horizontal.png` / `logo-horizontal.svg` | Main website header/logo lockup |
| `logo-horizontal-tight.png` | Tighter crop for compact layouts |
| `logo-horizontal-760.png` | Smaller header-ready raster export |
| `logo-mark.png` / `logo-mark.svg` | Standalone mark from the original left-side symbol |
| `favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `favicon-48.png` | Browser favicons |
| `apple-touch-icon.png` | iOS home screen icon |
| `android-chrome-192.png`, `android-chrome-512.png` | Android/PWA icons |
| `og-image.png` | Open Graph webpage thumbnail, 1200 x 630 |
| `twitter-card.png` | Twitter/X large card thumbnail, 1200 x 675 |
| `webpage-thumbnail.png` | Generic webpage/social thumbnail, 1200 x 630 |
| `html-head-snippet.html` | Drop-in favicon/social meta tags |
| `site.webmanifest` | Minimal PWA/icon manifest |
| `source-original-logo.png` | Preserved original uploaded logo |

Note: the SVG files are self-contained SVG wrappers with embedded PNGs. This keeps them visually identical to the generated logo rather than converting them into approximate vector art.
